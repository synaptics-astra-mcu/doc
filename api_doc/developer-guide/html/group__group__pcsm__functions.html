pcsm_set_wakeup()

Set wakeup event mask and polarity for a PCSM instance.

Parameters:

  • id: PCSM instance identifier.
  • mask: Wakeup source bitmask to configure.
  • pol: Wakeup polarity bitmask corresponding to mask bits.

Return: 0 on success, otherwise a pcsm_err_e negative error code.

Return values:

  • PCSM_OK: Wakeup mask and polarity configured successfully.
  • PCSM_ERR_INVALID_PARAM: Invalid PCSM instance identifier.

pcsm_get_wakeup_mask()

Get wakeup event mask for a PCSM instance.

Parameters:

  • id: PCSM instance identifier.
  • mask: Pointer to receive current wakeup mask bits.

Return: 0 on success, otherwise a pcsm_err_e negative error code.

Return values:

  • PCSM_OK: Wakeup mask read successfully.
  • PCSM_ERR_INVALID_PARAM: Invalid PCSM instance identifier or NULL mask pointer.

is_power_domain_stable()

Check whether the power domain is stable-on.

Parameters:

  • id: PCSM instance identifier.

Return: 1 if stable-on, 0 if not stable-on, otherwise a pcsm_err_e negative error code.

Return values:

  • 1: Power domain is stable-on.
  • 0: Power domain is not stable-on.
  • PCSM_ERR_INVALID_PARAM: Invalid PCSM instance identifier.
  • PCSM_ERR_NOT_SUPPORTED: State-status feature is not supported on this SoC.

pcsm_clear_wakeup_mask()

Clear wakeup event mask bits for a PCSM instance.

Parameters:

  • id: PCSM instance identifier.
  • mask: Wakeup mask bits to clear.

Return: 0 on success, otherwise a pcsm_err_e negative error code.

Return values:

  • PCSM_OK: Wakeup mask bits cleared successfully.
  • PCSM_ERR_INVALID_PARAM: Invalid PCSM instance identifier.

get_power_state()

Get current power state from PCSM.

Parameters:

  • id: PCSM instance identifier.
  • state: Pointer to receive current power state value.

Return: 0 on success, otherwise a pcsm_err_e negative error code.

Return values:

  • PCSM_OK: Power-state value read successfully.
  • PCSM_ERR_INVALID_PARAM: Invalid PCSM instance identifier or NULL state pointer.
  • PCSM_ERR_NOT_SUPPORTED: Power-state readback is not supported on this SoC.

pcsm_ctrl_config_ds_mode()

Configure PCSM CTRL register behavior for target deep-sleep mode.

Mode mapping:

  • PM_STATE_ON: sleep and deep-sleep disabled.
  • PM_STATE_MEM_RET: sleep enabled, deep-sleep disabled.
  • PM_STATE_FULL_RET: sleep and deep-sleep enabled.
  • PM_STATE_STANDBY: sleep and deep-sleep enabled.

Parameters:

  • id: PCSM instance identifier.
  • ds_mode: Target power mode to configure.

Return: 0 on success, otherwise a pcsm_err_e negative error code.

Return values:

  • PCSM_OK: Deep-sleep mode control configured successfully.
  • PCSM_ERR_INVALID_PARAM: Invalid PCSM instance identifier or unsupported ds_mode.
