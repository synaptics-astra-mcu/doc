ppu_set_power_mode()

Updates the default power policy field in the target instance PPU policy register.

Parameters:

  • id: PPU instance identifier.
  • mode: Target default power policy value (power_state_e).

Return: 0 on success, negative value on failure.

Return values:

  • 0: Power mode configured successfully.
  • -1: Invalid PPU instance identifier.

ppu_set_dynamic_transition()

Programs dynamic transition enable/disable in the target instance PPU policy register.

Parameters:

  • id: PPU instance identifier.
  • enable: true to enable dynamic transition, false to disable.

Return: 0 on success, negative value on failure.

Return values:

  • 0: Dynamic transition state updated successfully.
  • -1: Invalid PPU instance identifier.
