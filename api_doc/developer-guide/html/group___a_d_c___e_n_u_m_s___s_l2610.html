enum adc_conv_type_en

ADC conversion type — trigger / sequencer mode.

Enumerator
ADC_CONV_TYPE_SINGLE 

Single-shot: one conversion per START_CONV pulse.

ADC_CONV_TYPE_CONTINUOUS 

Continuous: conversions repeat at CONT_CONV_INTV rate.

ADC_CONV_TYPE_WINDOW 

Window comparison: interrupt when result is out of range.

ADC_CONV_TYPE_RESERVED 

Reserved — do not use.
