Detailed Description

The DMIC driver configures and controls digital microphone capture pipelines with FIFO and DMA transfer models.

Supported capabilities include channel I/O configuration, runtime gain/boost controls, blocking and non-blocking reads, callback-based event notification, and unified data-path programming using FIFO or DMA descriptors.

Typical usage flow:

  1. Initialize using dmic_init.
  2. Configure clocks/input parameters with dmic_configure_io and channel behavior with dmic_config_channel.
  3. Configure transfer path using dmic_config_data_path.
  4. Optionally register callback via dmic_register_callback.
  5. Enable and start capture using dmic_enable and dmic_start.
  6. Read samples via dmic_read/dmic_read_nonblocking.
  7. Stop and disable using dmic_stop and dmic_disable.
