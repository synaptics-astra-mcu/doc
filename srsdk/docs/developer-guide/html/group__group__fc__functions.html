fc_init()

Initialize FC driver instance and SoC-level FC hardware.

Parameters:

  • id: fc_instance_en instance identifier.

Return: fc_status_en status code.

Return values:

  • FC_OK: Initialization successful.
  • FC_ERROR_PARAMETER: Invalid FC instance identifier.
  • FC_ERROR_BUSY: Instance already initialized.
  • FC_ERROR: SoC-level initialization failed.

fc_deinit()

Deinitialize FC driver instance and disable FC resources.

Parameters:

  • id: fc_instance_en instance identifier.

Return: fc_status_en status code.

Return values:

  • FC_OK: Deinitialization successful, or instance already deinitialized.
  • FC_ERROR_PARAMETER: Invalid FC instance identifier.

fc_config_fault()

Configure one FC fault input source type and logging mask.

Parameters:

  • id: fc_instance_en instance identifier.
  • cfg: Pointer to fc_fault_config_t.

Return: fc_status_en status code.

Return values:

  • FC_OK: Fault configuration applied successfully.
  • FC_ERROR_PARAMETER: Invalid instance, NULL cfg, invalid fault ID, or invalid fault type.
  • FC_ERROR_NOT_INITIALIZED: Instance not initialized.

fc_set_fault_association()

Program fault routing table for interrupt, trigger, or reset output.

Parameters:

  • id: fc_instance_en instance identifier.
  • type: fc_assoc_type_en association table selector.
  • assoc_id: Selected output index in the chosen association table type.
  • assoc: Pointer to fc_fault_assoc_t bitmap content.

Return: fc_status_en status code.

Return values:

  • FC_OK: Association table programmed successfully.
  • FC_ERROR_PARAMETER: Invalid instance, invalid type/index combination, or NULL assoc.
  • FC_ERROR_NOT_INITIALIZED: Instance not initialized.

fc_read_log()

Read one FC log entry by index.

Parameters:

  • id: fc_instance_en instance identifier.
  • index: Log index in hardware fault log array.
  • entry: Pointer to fc_log_entry_t receiver.

Return: fc_status_en status code.

Return values:

  • FC_OK: Log entry read successfully.
  • FC_ERROR_PARAMETER: Invalid instance, NULL entry, or out-of-range index.
  • FC_ERROR_NOT_INITIALIZED: Instance not initialized.

fc_read_logs()

Read multiple FC log entries in chronological order from oldest retained log.

Parameters:

  • id: fc_instance_en instance identifier.
  • entries: Output array of fc_log_entry_t.
  • max_entries: Maximum entries to read into entries.
  • read_count: Pointer to receive number of entries actually read.

Return: fc_status_en status code.

Return values:

  • FC_OK: Log entries read successfully.
  • FC_ERROR_PARAMETER: Invalid instance, NULL read_count, or NULL entries when max_entries is nonzero.
  • FC_ERROR_NOT_INITIALIZED: Instance not initialized.
